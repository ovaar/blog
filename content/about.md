# About

I'm Thomas Reynders, a software engineer from Leeuwarden in the Netherlands.

I lead the customization team at [Elfsquad](https://www.elfsquad.io), where we build 3D product configurators for manufacturers. That is the part of CPQ (configure, price, quote) where a customer sees their machine, boat or building change as they choose options.

## What I work on

* **3D on the web**: React Three Fiber, Three.js, glTF, and a conversion pipeline from Autodesk Platform Services (Forge) SVF to glTF.
* **Parametric CAD in the browser**: B-rep modelling, STEP export, WebAssembly.
* **Customer-specific configurators** in TypeScript and React, from Figma design to production.
* **AI-assisted engineering**: agentic coding workflows, MCP servers, automated code review.

Next to the engineering I coach my colleagues, and I set up how we run client projects, from the first conversation to production.

## Before Elfsquad

* **BIMcollab** (2021 - 2026): high-performance C++ desktop software for large BIM models. C++17/23, Conan, CMake, Azure DevOps.
* **TOPIC Embedded Systems** (2016 - 2021): consultant on embedded Linux (Yocto), medical software, quantum experiment tooling and C#/WPF control software.

Writing things down is how I make sure I understand them. Most posts here started as notes for a colleague.
